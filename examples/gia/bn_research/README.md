# BN Statistics Research (Experimental)

> **Status: experimental / not maintained.** This directory holds in-progress research scripts exploring modifications to batch-norm-based gradient inversion attacks (`attack_modifications.py`) on CIFAR-10/100. It is not a clean, reproducible example and is likely to be removed. Refer to [huang_cifar10_16_images](../huang_cifar10_16_images/README.md), [GIA_base](../GIA_base/README.md), and [GIA_base_running](../GIA_base_running/README.md) for the supported, documented BN-statistics attack examples.
